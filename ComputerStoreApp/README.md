# WPF-приложение интернет-магазина на основе Entity Framework

Этот проект представляет собой десктопное приложение на Windows Presentation Foundation (WPF) для автоматизации работы интернет-магазина компьютерной техники. Программа использует базу данных Microsoft SQL Server и технологию ADO.NET Entity Data Model (EDMX) для работы с данными. Приложение поддерживает систему ролей (гость, покупатель, менеджер, администратор) и позволяет оформлять заказы. 

## Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/ComputerStoreApp.git
   cd ComputerStoreApp
Разверните базу данных:
Откройте Microsoft SQL Server Management Studio (SSMS) и выполните SQL-скрипт для создания базы данных ComputerStoreDB и таблиц.

Откройте файл решения:
Запустите ComputerStoreApp.sln в Visual Studio. Проверьте строку подключения в App.config.

Соберите проект:
Нажмите «Сборка» -> «Пересобрать решение» (убедитесь, что установлен пакет EntityFramework 6.4.4).

Структура проекта
/Entities/: Папка с EDMX-моделью базы данных и сгенерированными классами.

/MainWindow.xaml: Главное окно приложения (навигация).

/PageLogin.xaml: Страница авторизации.

/PageRegister.xaml: Страница регистрации.

/PageCatalog.xaml: Каталог товаров и оформление заказа.

/PageOrders.xaml: Просмотр и удаление заказов.

/App.xaml: Точка входа и глобальный контекст БД.

Данные
Используется локальная база данных Microsoft SQL Server (ComputerStoreDB).
Основные таблицы: Users (пользователи), Roles (роли), Products (товары), Categories (категории), Orders (заказы) и OrderItems (состав заказов). Связи между таблицами реализованы через внешние ключи (Foreign Keys).
